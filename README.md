# hxyfront-62014 训放成绩公示与申诉复核台

源提示词编号：9 ｜ 端口 62014

训放成绩贴榜后，鸽主拿报时或健康备注来问时使用的成绩公示与申诉复核工具。

## 功能规则

- 登记每场赛事的**地点、距离、天气、司放时刻**，逐羽登记**归巢时刻与健康状态**（健康 / 轻伤 / 重伤 / 异常）。
- **未归巢（含归巢时刻早于司放的报时异常）不进速度榜**，只给归巢羽按分速排名。
- 鸽主可就**报时**或**健康备注**发起申诉：同羽同场只保留一条未结申诉；未结期间榜面标"待定"、停发证书。
- 两名复核员**分别独立**给"维持 / 改判"意见（先提交即封存），**两人均改判**才按申请内容更新成绩并重算名次与提醒；任一维持即维持原榜。
- 任何更正（登记更正、赛事信息更正、改判成立）生效前自动**旧版留档**，档案页可逐版对比名次升降；申诉带完整操作轨迹。
- 筛选（足环号/鸽主/血统、健康、申诉状态）在榜面、复核台、档案三页通用；复核台可"榜面定位 / 档案跟随"，跨页只看被复核的那一羽。

## 源码分层

| 文件 | 职责 |
| --- | --- |
| `src/judging.ts` | 判定层（纯函数）：分速/名次、提醒、证书状态、两人投票与改判规则、版本对比 |
| `src/storage.ts` | 存档层：赛事/登记/申诉/榜次版本的唯一数据源，localStorage 持久化、更正前留档 |
| `src/App.tsx` | 界面层：成绩公示榜、申诉复核台、历史档案三个页签，筛选与跟随复核 |

## 本地运行

```bash
npm install
npm run dev
```

类型检查：`npx tsc --noEmit`；构建：`npm run build`。

演示数据内置一场 300 公里秋训（8 羽，含未归巢、重伤、一条已改判成立的报时申诉、一条未结申诉），点"重置演示数据"可还原。
