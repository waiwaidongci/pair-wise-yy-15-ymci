# hxyfront-62014 训放成绩公示与申诉复核台

源提示词编号：9（在“赛鸽训放记录”基础上补齐成绩公示与申诉复核流程）

## 业务规则

- 登记：训放地点、放飞距离、天气、放飞时刻、归巢时刻、健康状态与备注。
- 速度榜：归巢时刻有效才入榜，分速 = 距离(米) / 飞行时长(分)，按场内分速降序，并列同名次；
  **未归巢不进速度榜**，只进未归巢提醒。
- 贴榜公示：登记完成后贴榜，留存“公示初榜 v1”；贴榜后原始登记锁定，更正只能走申诉。
- 申诉：鸽主持报时或健康备注发起（报时更正 / 健康备注两类），
  **同羽同场只留一条未结申诉**。
- 合议：两位复核员（裁判长、仲裁委）分别独立给出“维持 / 改判”意见，
  **两席均改判才更新成绩**；任一席维持或缺席，定案后维持原榜。
- 未结申诉：榜面名次标“待定”，该羽**停发证书**；改判后按新值更正，
  **名次、分速、提醒全部按新值重算**，落新版（v2、v3…），**旧版留档**可查；维持不产生新版。
- 筛选（短/中/长距离、天气、健康、待定、足环/鸽主/血统）同时作用于当前公示榜、历史留档与单羽档案；
  档案取复核后的现值。

## 源码分工（三个文件）

| 文件 | 职责 |
| --- | --- |
| `src/judge.ts` | 判定层：分速/名次、未归巢、提醒、待定标记、申诉合议规则（纯函数） |
| `src/archive.ts` | 存档层：公示初榜 v1、改判前旧版快照留档、版本落版 |
| `src/App.tsx` | 界面层：登记/贴榜、成绩公示、申诉复核台、版本留档、单羽档案 |
